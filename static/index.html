THE PROBLEM

Tech debt that nobody scheduled time to notice

A "pure math utility" module starts writing files. A "logging helper" starts triggering business logic. Nobody catches this as it happens — it surfaces later, during onboarding, or as a surprise in a code review.

Codebase Autopsy combines fast, deterministic static analysis with IBM Bob 2.0's repo-aware reasoning to catch this automatically, and rank it by how bad the drift actually is.

HOW IT WORKS

Four stages, one real AI call where it counts

01
Ingest
Walk the repo, parse every .py file with Python's ast module.
02
Graph
Build a dependency graph, detect import cycles. No AI needed here.
03
Bob 2.0
For each documented module, judge declared vs. actual behavior.
04
Report
Rank modules by drift score, surface evidence and cycles.

02
